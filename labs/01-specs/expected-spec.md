## Spec: Limit how many items customers can order

**Goal:** Checkout rejects any order with more than 10 of one product and tells the customer the maximum.

**Acceptance criteria** (each one is a test someone could write)
1. Given an order of `{"mug": 10}`, when it is checked out, then it returns status 200 with `total_cents` 12000. Exactly 10 is allowed.
2. Given an order of `{"mug": 11}`, when it is checked out, then it returns status 400 with no total, and the error names both `mug` and the maximum `10`.
3. Given an order of `{"mug": 10, "tshirt": 10, "poster": 10}`, when it is checked out, then it returns status 200. The limit applies to each product separately, not to the whole order.
4. Given the limit is a single named constant in `shop/service.py` and a test sets it to 5, when `{"mug": 6}` is checked out, then it returns 400 and the error says the maximum is 5. Changing that one number is the only step needed to tune the limit.

**Out of scope** (pruned, and why)
- Limits per customer or across orders: answer 1 says the limit applies within a single order only.
- Different limits for different products: answer 2 says it's the same for every product for now. No per-product field in `repo.PRODUCTS`.
- Capping the quantity at 10 and accepting the order: answer 3 says to reject and never silently change the quantity.
- "Configurable" as an environment variable, settings file or admin screen: answer 4 says engineering edits the number in code about once a year. A constant is enough, per AGENTS.md's "no config for a value that never changes".
- A cap on the order's total item count, or exemptions for bulk or wholesale buyers: answer 5 says no other limits, just the count per product.
- Changes to the storefront quantity box: this repo has no UI, and the ticket asks for the check at checkout.

**Touches:** `shop/service.py` (the constant, plus a check next to the existing `qty < 1` check at line 12) · `tests/test_shop.py` (the four criteria above). `shop/api.py` doesn't change, because it already turns a `ValueError` into a 400.

**Still open for human judgement:** The exact wording of the error. The criteria only require that it names the product and the maximum.
